# 아이스브레이커

준비물도 연습도 없는 아이스브레이킹 게임 5선.
처음 만난 자리에서 폰 하나로 바로 꺼낸다.

> **이 앱은 `kyulolong.com/trick/` 에 얹혀 있다.** 경로 위에 사는 앱이라 따로 지켜야 할 것들이 있다 —
> 끝 슬래시·자산 경로·파비콘·SEO·배포 순서. 손대기 전에
> [규로롱 서비스 체크리스트](https://github.com/Kyulolong/kyulolong-site/blob/main/docs/SERVICE-CHECKLIST.md)를 읽을 것.

## 다섯 가지

| | 무엇 | 관객이 하는 일 |
| --- | --- | --- |
| 🃏 **사라지는 카드** | 전원이 기억한 카드가 전부 동시에 사라진다 | 카드 한 장 외우기 |
| 🎲 **요트 다이스** | 세 번 굴려 족보 12칸을 채우는 주사위 게임 (2~6명) | 폰 돌려 굴리기 · 기록 |
| 🧠 **없던 기억** | 한 번도 없던 단어를 다 같이 "봤다"고 확신한다 (DRM) | 보기 |
| 🕵️ **라이어** | 한 명만 다른 단어를 받는데, 본인도 모른다 | 폰 돌려 단어 확인 · 토론 |
| 👉 **동시에 지목** | 셋 세면 다 같이 한 사람을 가리킨다 | 손가락 들기 |

## 설계 규칙

이 앱에는 원래 열 개가 있었고, 아홉 개를 버렸다. 버린 것들의 공통점이 규칙이 됐다.

- **관객에게 절차를 시키지 않는다.** 암산·카운팅·다단계 지시가 들어가는 순간
  누군가는 틀리고, 틀리면 마술이 아니라 검산이 된다. 우와 셋은 관객이 **보기만** 한다.
- **전원이 동시에 참여한다.** 한 명씩 돌아가며 하는 것은 나머지가 구경꾼이 된다.
  예외인 라이어·요트 다이스는 `폰 돌리기` 태그를 달아 구분한다. 요트는 계산을 앱이 전부 하고,
  남의 차례에도 다 같이 주사위를 보며 소리 지르는 게임이라 남겼다.
- **100% 성공한다.** 확률에 기대지 않는다. 가짜기억은 속임수가 아니라
  재현되는 인지 현상이라 진행자가 실수할 여지가 없다.
  (변화맹 '사라진 거 찾기'는 실제로 해보니 너무 쉽게 찾아서 요트 다이스로 교체했다.)

원리와 진행 팁은 앱 안의 `?` 버튼에 들어 있다. 공연 중에는 열지 말 것.

## 구조

단일 파일 정적 사이트. 빌드 과정도 외부 의존성도 없다.

```
index.html                모든 것 (HTML · CSS · JS)
manifest.webmanifest      start_url · scope 는 /trick/
sw.js                     오프라인 캐시 (한 번 열면 네트워크 없이도 동작)
icon-16/32/180/512.png    탭 · 홈 화면 아이콘
og.png                    1200×630 공유 카드
brand/                    아이콘 SVG 원본 (서빙하지 않는다)
Dockerfile · nginx.conf   Coolify 배포
```

### 오프라인

`sw.js` 가 index.html 과 아이콘을 캐시한다. 외부 의존성이 없어서 이것만으로 다섯 게임이 전부 오프라인에서 돈다.
페이지는 네트워크 우선(3초 넘으면 캐시)이라 배포는 바로 보인다. 앱 코드만 고친 배포에서는 `sw.js` 를 건드릴 필요가 없고,
**아이콘·매니페스트를 바꿨을 때만** `sw.js` 의 `CACHE` 버전을 올린다.

### 로컬에서 보기

```bash
open index.html            # 빌드 없음. 그냥 열면 된다
```

경로가 걸린 것(매니페스트·아이콘)까지 확인하려면 슬러그를 흉내 내야 한다:

```bash
docker build -t trick . && docker run --rm -p 8080:80 trick
# http://localhost:8080
```

### 배포

Coolify 빌드팩 **Dockerfile**, 포트 **80**.
빌드 타임 변수가 없으므로 `Use Docker Build Secrets` 는 끈 채로 둔다.

배포 후 검증은 체크리스트 §8 을 그대로 쓴다 (`S=trick`).
